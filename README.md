# Крестики-нолики 3×3: человек против ИИ

Консольная игра на Python с полным перебором дерева Minimax.
ИИ выбирает оптимальные ходы и не проигрывает при корректной игре по правилам.
При оптимальной игре обеих сторон получается ничья.

## Запуск

Нужен **Python 3.8 или новее**. Сторонние библиотеки не требуются.
Распакуйте архив и откройте терминал в папке с `main.py`.

Windows:

```bash
py main.py
```

Linux / macOS:

```bash
python3 main.py
```

Если интерпретатор доступен как `python`, используйте `python main.py`.

## Управление

1. Выберите `X` или `O` латинскими буквами. X всегда ходит первым.
2. Введите номер свободной клетки от `1` до `9` и нажмите Enter.
3. ИИ ответит автоматически. Игра заканчивается победой или ничьей.
4. Для выхода введите `q` или нажмите Ctrl+C. Для новой партии запустите программу снова.

Номера клеток по строкам: `1 2 3`, затем `4 5 6`, затем `7 8 9`.
В поле свободные клетки показаны номерами, занятые — символами игроков.
Неверный ввод и попытка занять занятую клетку приводят к повторному запросу.
Первый ход ИИ может потребовать небольшого ожидания: перебирается всё дерево.

## Файлы

- `main.py` — состояние, правила, Minimax и консольная игра.
- `REPORT.md` — краткий отчёт по заданию.
- `test_game.py` — автоматические проверки, включая перебор всех ответов человека.

## Проверка

Из папки проекта:

```bash
python3 -m unittest -v
```

На Windows можно использовать `py -m unittest -v`.
Проверка перебирает все допустимые ходы человека против выбранной ИИ стратегии
для обеих ролей ИИ: X и O. В каждой конечной позиции проверяется отсутствие поражения.

## Соответствие заданию

| Компонент | Реализация |
|---|---|
| Структура состояния | `GameState` |
| Допустимые ходы | `get_legal_moves(state)` |
| Применение хода | `apply_move(state, move)` |
| Терминальное состояние | `terminal_result(state)` |
| Оценочная функция | `evaluate(state)` |
| Рекурсивный поиск | `minimax(state, depth, is_maximizing)` |
| Лучший ход | `choose_best_move(state)` |
| Человек против ИИ | `play()` |

Дерево строится при рекурсивном обходе: каждое применение хода создаёт дочернее
состояние. Отдельный объект дерева и сохранение всех узлов не требуются.
Кэширование, отсечение ветвей и эвристическое ограничение глубины не используются.
